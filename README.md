# 🎯 Guessy - Number Guessing Game

A fun and interactive number guessing game built using pure HTML, CSS, and JavaScript.

## 🚀 Features

* 4 Difficulty Levels

  * 🌱 Easy (1–100)
  * 🔥 Medium (1–500)
  * 💀 Hard (1–1000)
  * 👾 Impossible (1–10000)

* Level Unlock System

* Lives/Heart System

* Higher or Lower Hints

* Guess History Tracking

* Win & Loss Statistics

* Streak Counter

* Best Score Tracking

* Confetti Celebration Effects

* Responsive Design

* Modern UI with Animations

* Special Hints in Impossible Mode

## 🎮 How to Play

1. Select a difficulty level.
2. Guess the secret number.
3. Use the hints to determine whether the number is higher or lower.
4. Find the correct number before running out of lives.
5. Unlock harder levels by winning previous levels.

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (Vanilla)

## 📱 Responsive Design

The game is optimized for:

* Desktop
* Tablet
* Mobile Devices
